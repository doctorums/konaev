# Заметки для Claude по проекту konaev.tv

## Как работать с владельцем репозитория

- Работает только с iPad (Safari/Brave), без devtools: вся диагностика — на экране
  (скриншоты, `/diag` воркера, скрытая диагностика канала эха — 5 тапов по заголовку).
- Общение по-русски, коротко: что сделать — пунктами, без лишних слов.
- Файлы с кодом (например, `workers/konaev-echo.js` для вставки в Cloudflare)
  отдавать через SendUserFile с `display: "render"` — в режиме просмотра, откуда
  код можно скопировать. Не `attach`: так файл на iPad не копируется.
- Ссылки на превью ветки — githack на конкретный коммит
  (`raw.githack.com/doctorums/konaev/<sha>/index.html`): по имени ветки githack кэширует.

## Правила репозитория

- В `main` напрямую не пушить: ветка → PR → слияние по команде владельца.
- `index.html`: весь сайт-телевизор лежит в атрибуте `srcdoc` у `<iframe id="proto">`
  (HTML-экранирован). Снаружи — заставка. Правки сайта — внутри `srcdoc`;
  после правки сверять, что снаружи байт в байт как в `main` (если заставку не трогали).
- Казахский словарь — `i18n/kk.js` (русская фраза → казахская), черновик на вычитке.
- Воркер `konaev-echo` деплоится вручную из дашборда Cloudflare; `workers/` — снимок.
  Проверки воркера: `/run`, `/diag`, `/probe?url=` (с `?key=`).
