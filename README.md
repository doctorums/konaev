# konaev.tv

Сайт-телевизор. Кабельное телевидение в Конаеве.

`index.html` — одностраничный прототип, без сборки и без зависимостей,
кроме шрифтов с Google Fonts. Открывается файлом, работает статикой.

`i18n/kk.csv` — казахский словарь, таблица из трёх столбцов: `ru` — фраза
точно как на сайте, `kk` — перевод, `где` — подсказка, где она стоит.
Править можно прямо на GitHub (карандаш) или в Google Таблицах / Excel /
Numbers с сохранением в CSV (UTF-8). Меняйте только столбец `kk`. Пустая
ячейка `kk` — фраза остаётся русской. Нет файла — сайт работает по-русски.
Язык: `?lang=kk` / `?lang=ru` в адресе, кнопка ҚАЗ/РУС на экране или язык
устройства. Словарь грузится через сеть, поэтому при открытии `index.html`
файлом с диска казахского не будет.
