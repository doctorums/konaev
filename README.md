# konaev.tv

Сайт-телевизор. Кабельное телевидение в Конаеве.

`index.html` — одностраничный прототип, без сборки и без зависимостей,
кроме шрифтов с Google Fonts. Открывается файлом, работает статикой.

`i18n/kk.js` — казахский словарь: русская фраза → казахская. Править можно
прямо на GitHub (карандаш), сайт подхватит после слияния в main. Нет файла —
сайт работает по-русски. Язык: `?lang=kk` / `?lang=ru` в адресе, кнопка
ҚАЗ/РУС на экране или язык устройства.
